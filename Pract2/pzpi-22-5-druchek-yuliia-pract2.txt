2 ХІД РОБОТИ


У ході практичного заняття було створено презентацію на тему "Методи рефакторингу коду програмного забезпечення". Слайди до презентації наведено у додатку А. 


Рефакторинг — це процес зміни структури коду без зміни його зовнішньої поведінки. Метою рефакторингу є покращення якості коду, його зрозумілості, зменшення складності, поліпшення підтримки та тестованості. Рефакторинг може включати перейменування змінних, видалення дублювання, покращення модульності, зміну алгоритмів або оптимізацію продуктивності без внесення змін у логіку програми.


Рекомендація: Переносьте поле до класу, який його використовує найбільше.
Опис: Перенесення поля з одного класу до іншого дозволяє зменшити дублювання даних та залежностей, покращити інкапсуляцію і забезпечити, щоб дані зберігалися там, де вони логічно належать. Це допомагає зробити клас більш самодостатнім і зручним для використання.


Рекомендація: Замінюйте масиви на об'єкти.
Опис: Масиви менш зрозумілі для роботи, якщо елементи не мають чітко визначених імен. Заміна масиву об'єктом із властивостями робить структуру даних зрозумілішою, полегшує доступ до конкретних значень і знижує ризик помилок через неправильний порядок елементів у масиві. Це також спрощує розширення, якщо потрібно додати нові поля.


Рекомендація: Ховайте методи, які не повинні бути доступними зовні.
Опис: Якщо метод призначений лише для внутрішнього використання класу або повинен викликатися через інший керуючий клас, приховання методу забезпечує кращу інкапсуляцію та зменшує ризик некоректного використання. Використання обмежень доступу, таких як private або internal, дозволяє краще контролювати поведінку класу і його взаємодію з іншими частинами програми.


Методи рефакторингу розглядалися на прикладі коду написаного на мові програмування C#. Використані приклади коду наведено у додатку Б.

Код до рефакторингу:


using System;


public class User
{
    public string[] Info = new string[3]; 
    public string Role; 


    public void PrintInfo()
    {
        Console.WriteLine($"Name: {Info[0]}, Email: {Info[1]}, Role: {Role}");
    }
}


public class UserManager
{
    public User CreateUser(string name, string email, string role)
    {
        User user = new User
        {
            Info = new string[] { name, email, role },
            Role = role 
        };


        return user;
    }


    public void AssignRole(User user, string role)
    {
        user.Role = role;
        user.Info[2] = role; 
    }


    public void PrintUserDetails(User user)
    {
        user.PrintInfo(); 
    }
}


public class Program
{
    public static void Main()
    {
        UserManager manager = new UserManager();
        User user = manager.CreateUser("Alice", "alice@example.com", "Admin");
        manager.PrintUserDetails(user);


        manager.AssignRole(user, "User");
        manager.PrintUserDetails(user);
    }
}


Код після рефакторингу:


public class User
{
    private UserInfo _info; 


    public User(string name, string email, string role)
    {
        _info = new UserInfo(name, email, role);
    }


    public void SetRole(string role)
    {
        _info.Role = role;
    }


    internal void PrintInfo()
    {
        Console.WriteLine($"Name: {_info.Name}, Email: {_info.Email}, Role: {_info.Role}");
    }


    private class UserInfo(string name, string email, string role) 
    {
        public string Name { get; set; } = name;
        public string Email { get; set; } = email;
        public string Role { get; set; } = role;
    }
}


public class UserManager
{
    public User CreateUser(string name, string email, string role)
    {
        return new User(name, email, role);
    }


    public void AssignRole(User user, string role)
    {
        user.SetRole(role); 
    }


    public void PrintUserDetails(User user)
    {
        user.PrintInfo(); 
    }
}


public class Program
{
    public static void Main()
    {
        UserManager manager = new();
        User user = manager.CreateUser("Alice", "alice@example.com", "Admin");
        manager.PrintUserDetails(user);


        manager.AssignRole(user, "User");
        manager.PrintUserDetails(user);
    }
}
